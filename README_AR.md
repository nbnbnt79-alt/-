# مشروع حجالة لأندرويد (نسخة أولية Offline-first)

هذه حزمة مصدر لتغليف ملف HTML المرفق داخل تطبيق Android باستخدام Capacitor. ملف الواجهة الأساسي موجود محلياً في `web/index.html`، لذلك يمكن فتح الواجهة دون استضافة صفحة ويب.

## بناء APK من الهاتف فقط (عبر GitHub Actions)

> تحتاج إلى اتصال إنترنت أثناء البناء وحساب GitHub. عملية البناء تتم على خوادم GitHub، وليس داخل الهاتف.

1. فك ضغط `HajalaAndroid_Offline_First.zip` على الهاتف.
2. أنشئ مستودعاً جديداً في GitHub باسم `hajala-android` واجعله Private إن كنت لا تريد نشر الكود للعامة.
3. ارفع محتويات مجلد `HajalaAndroid` إلى جذر المستودع، مع الحفاظ على المسارات، بما فيها `.github/workflows/android-apk.yml`. إذا لم تظهر المجلدات التي تبدأ بنقطة في أداة الرفع، أنشئ ملف سير العمل من واجهة GitHub يدوياً بنفس المسار.
4. افتح تبويب **Actions** في المستودع، واختر **Build Hajala APK** ثم **Run workflow**.
5. انتظر حتى تنتهي المهمة بنجاح، ثم افتح تشغيل المهمة وانزل إلى **Artifacts** واضغط `Hajala-debug-APK` لتنزيل ZIP.
6. فك ضغط ملف Artifact، ثم ثبّت `app-debug.apk`. قد يطلب Android السماح بالتثبيت من هذا المصدر.

## ملاحظات عن البناء
- سير العمل ينشئ مشروع Android بواسطة Capacitor ويبني نسخة Debug APK غير مخصصة للنشر على المتجر.
- لا يتطلب سير العمل رفع مفاتيح توقيع خاصة.
- البناء عبر GitHub يحتاج إنترنت أثناء العملية، لكن التطبيق بعد تثبيته يمكنه فتح ملف الواجهة المحلي.

## حدود العمل دون إنترنت
فحص الملف الأصلي أظهر اعتماديات وخدمات خارجية أو محلية، منها خدمة ترجمة MyMemory ومكتبات تُحمّل عبر CDN مثل JSZip وTesseract وMux وONNX Runtime ونموذج تلوين من Hugging Face. كما توجد طلبات إلى `127.0.0.1:8765` و`127.0.0.1:8787` لمعالجة بعض الوظائف. لذلك لا يمكن ضمان عمل كل الميزات دون إنترنت بمجرد تغليف HTML. يلزم نقل المكتبات والنماذج محلياً وتوفير بدائل للخدمات الخارجية، كما يلزم تشغيل أو إعادة بناء الخوادم المحلية التي يتوقعها الملف.

هذه الحزمة ليست APK مبنياً أو مختبراً؛ إنها مصدر وسير عمل آلي لمحاولة إنتاج APK. يجب مراجعة سجلات البناء إذا فشلت المهمة.

## أيقونة التطبيق
- التصميم المعتمد موجود في `resources/hajala-icon.png`.
- أثناء بناء APK، يثبت سير العمل الأيقونة تلقائياً بأحجام Android المختلفة، بما فيها أيقونة Adaptive لأجهزة Android الحديثة.
